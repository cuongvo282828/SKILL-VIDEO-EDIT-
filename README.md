## Sử dụng
Cung cấp SKILL.md và tài liệu liên quan cho công cụ/agent dựng video, hoặc clone repo để làm việc với chúng. Repo chưa chứa renderer, footage nguồn hay file video MP4; video final được liên kết từ ghi chú dự án.

## Cập nhật
Đã bật Codex automation kiểm tra mỗi giờ và đồng bộ một chiều Drive → GitHub trên nhánh main. Chỉ tạo commit khi có thay đổi. Không có thay đổi thì không thông báo. Nếu lỗi truy cập hoặc có xung đột chỉnh sửa, automation sẽ báo thay vì ghi đè. Không xóa bản lưu khi file nguồn mất quyền hoặc bị xóa.
